Prywatność

Twoje dane zostają na Twoim Macu.

Monitoring Zasobów nie wymaga konta, nie zawiera reklam, analityki ani mechanizmów śledzących i nie wysyła danych użytkownika do autora.

Wersja dokumentu: 11 sierpnia 2026 r.

1. Dane przetwarzane przez aplikację

Aplikacja odczytuje lokalne informacje potrzebne do pokazania kondycji Maca: wykorzystanie CPU, GPU, pamięci, dysku i sieci, informacje o woluminach i urządzeniach oraz — w widoku szczegółowym — dane o aktywności procesów dostępne w macOS.

Warsztat może lokalnie analizować wskazane obszary dysku, aplikacje oraz powiązane pliki cache i logów. Elementy są przenoszone do Kosza wyłącznie po ręcznym wyborze i potwierdzeniu użytkownika.

2. Przechowywanie lokalne

Ustawienia, historia Warsztatu i snapshot dla zgodnych integracji Stream Deck pozostają na urządzeniu. Historia Warsztatu jest utrzymywana przez maksymalnie 90 dni, z limitami 500 operacji i 5000 pozycji.

Snapshot Stream Deck jest zapisywany atomowo w prywatnym katalogu Application Support. Katalog otrzymuje uprawnienia 0700, a plik 0600. Snapshot nie zawiera PID-ów, nazw, komend ani ścieżek procesów.

3. Sieć, analityka i śledzenie

Aplikacja nie zawiera SDK reklamowych ani analitycznych, nie tworzy kont i nie wysyła odczytów systemowych, historii ani ustawień do autora. Sprawdzanie trasy sieciowej i aktywności procesów odbywa się lokalnie z użyciem mechanizmów macOS.

4. Strona internetowa

Ta witryna nie ładuje trackerów, zewnętrznych fontów ani narzędzi analitycznych. Jest hostowana przez GitHub Pages, dlatego obsługę żądań mogą obejmować techniczne logi i zasady GitHub. Szczegóły opisuje GitHub General Privacy Statement.

5. Kontrola użytkownika

Ustawienia i dane aplikacji można usunąć standardowymi narzędziami macOS. Pliki przeniesione przez Warsztat pozostają w Koszu do czasu jego opróżnienia; część operacji można odwrócić z lokalnej Historii, zgodnie z zabezpieczeniami aplikacji.

6. Kontakt i wsparcie

Pytania o prywatność lub działanie aplikacji można zgłaszać w sekcji GitHub Issues.
